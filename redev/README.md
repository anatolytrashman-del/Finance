# Редевелопмент — платформа управления проектами

Streamlit-приложение для управления проектами редевелопмента коммерческой недвижимости
(купил объект → перепрофилировал/реконструировал → сдал в аренду или продал).

Отдельное от основного дашборда приложение. Работает поверх своей Google-таблицы.

## Что уже есть (блок 1)

- **Реестр проектов** — KPI (число проектов, суммарный бюджет, вложено, средняя готовность),
  фильтры по стадии и статусу, графики «проекты по стадиям» и «бюджет vs вложено», таблица-реестр.
- **Карточка проекта** — назначение (текущее → целевое), площади (участок / GBA / GLA),
  экономика (CAPEX, вложено, остаток), сроки, прогресс по стадиям.

Пока приложение открывается в **демо-режиме** (три примера проектов), чтобы сразу увидеть интерфейс.

## Подключение своей таблицы

1. Создай Google-таблицу с листом **«Проекты»**.
2. Первая строка — заголовки колонок (порядок любой, лишние игнорируются):

   | Колонка | Пример |
   |---|---|
   | Проект | Лофт-квартал «Красный Октябрь» |
   | Адрес | Берсеневская наб., 6 |
   | Город | Москва |
   | Координаты | 55.7415, 37.6083 |
   | Текущее назначение | Складской корпус |
   | Целевое назначение | Креативные офисы + ритейл |
   | Площадь участка (сот) | 42 |
   | Площадь здания (м²) | 8600 |
   | Аренд. площадь (м²) | 7100 |
   | Стадия | СМР |
   | Статус | Активен |
   | Готовность % | 55 |
   | Дата старта | 2025-03-01 |
   | План ввода | 2026-12-01 |
   | Бюджет CAPEX $ | 6800000 |
   | Вложено $ | 3900000 |
   | Ответственный | А. Иванов |
   | Комментарий | Демонтаж и усиление перекрытий |

   Стадии (для сортировки и воронки): `Поиск → Покупка → Проектирование → Согласования → СМР → Ввод → Эксплуатация → Продажа`.
   Числа можно писать как `6 800 000`, `6,8 млн`, `65%` — парсер поймёт.

3. **Файл → Настройки доступа** → «Все, у кого есть ссылка» → **Читатель**.
4. Вставь ID таблицы в `config.py` (`GOOGLE_SHEET_ID`).

## Запуск

```bash
cd redev
pip install -r requirements.txt
streamlit run app.py
```

## Структура

- `app.py` — навигация (`st.navigation`)
- `config.py` — ID таблицы, список стадий и статусов
- `data_source.py` — загрузка книги из Google Таблицы (+ демо-режим)
- `parsers.py` — разбор листа «Проекты», парсер чисел, демо-данные
- `store.py` — единая точка получения датафрейма проектов для вьюх
- `views/overview.py` — реестр проектов
- `views/project.py` — карточка проекта
