# Trashman Family Office

Веб-дашборд на Streamlit — учёт капитала, сделок, недвижимости, финмоделей и
мониторинг рынка (kufar/realt/bir.by). Все данные хранятся локально, в
SQLite-файле (`db.py`), — Google Таблица больше не используется приложением.

## Запуск локально

```bash
pip install -r requirements.txt
python3 -m playwright install chromium   # один раз — нужен для «Анализ рынка» (bir.by)
streamlit run app.py
```

Откроется `http://localhost:8501`. Все данные вводятся прямо в приложении —
на странице **«Ввод данных»** (прогресс капитала, сделки, объекты
недвижимости, помесячный срез баланса).

### Перенос истории из старой Google Таблицы (один раз)

Если раньше учёт вёлся в Google Таблице и её данные ещё доступны по ссылке:

```bash
python3 migrate_from_sheet.py
```

Скрипт скачивает таблицу и переносит всю историю (капитал, сделки,
недвижимость, все найденные помесячные срезы баланса) в
`~/.trashman_family_office/family_office.db`. Смотри docstring файла —
скрипт идемпотентен для баланса и прогресса капитала, но повторный запуск
задублирует сделки/объекты недвижимости.

## Деплой в облако (Fly.io)

Приложение упаковано в Docker и рассчитано на Fly.io — бесплатный лимит
хватает под личный некоммерческий трафик, есть persistent volume (данные не
теряются при передеплое) и HTTPS из коробки.

1. Установи `flyctl` и залогинься: https://fly.io/docs/hands-on/install-flyctl/
2. Создай volume для базы данных (один раз):
   ```bash
   fly volumes create family_office_data --region waw --size 1 --app <имя-из-fly.toml>
   ```
   (если ещё не создавал приложение — сначала `fly launch --no-deploy`, оно
   подхватит `fly.toml`; имя приложения там уже случайное, специально не
   выдающее назначение сервиса).
3. Задай пароль на вход (ОБЯЗАТЕЛЬНО перед первым деплоем):
   ```bash
   fly secrets set APP_PASSWORD='твой-пароль'
   ```
4. Если есть история из Google Таблицы — перенеси её **до** деплоя (см. выше),
   затем залей файл базы на volume:
   ```bash
   fly ssh sftp shell
   put ~/.trashman_family_office/family_office.db /data/family_office.db
   ```
5. Деплой:
   ```bash
   fly deploy
   ```

После деплоя приложение доступно по `https://<app>.fly.dev` (адрес из
`fly.toml`) — заходишь с телефона как на обычный сайт, вводишь пароль один
раз за сессию браузера. Машина по умолчанию засыпает при простое
(`auto_stop_machines`), чтобы не жечь бесплатный лимит впустую — первый
заход после паузы может занять несколько секунд на «пробуждение».

**Важно:** URL — единственная преграда для того, кто не знает пароль, чтобы
случайно набрести на страницу входа, но не замена самому паролю. Не
выкладывай ссылку в публичные места; если её кто-то узнал — смени пароль
(`fly secrets set APP_PASSWORD=...`) и, если нужно, пересоздай приложение под
новым случайным именем.

## Структура

- `app.py` — роутер навигации (запускается через `streamlit run app.py`), пароль на вход (`auth.py`), общий шрифт и логотип
- `views/dashboard.py` — дашборд капитала (KPI-карточки, капитал в $/₽, прирост по годам, долг/капитал, структура активов, доходы; последняя точка капитала/долга пересчитывается по текущему курсу bnb.by, см. `balance_live.py`)
- `views/balance.py` — баланс на последний срез: активы/обязательства по категориям, итого по портфелю
- `views/deals.py` — реестр сделок (инвестиции/продажи/дивиденды) с фильтрами по периоду
- `views/real_estate.py` — портфолио объектов недвижимости с картой и итогами
- `views/documents.py` — архив документов по объектам (ссылки на Google Диск)
- `views/ideas.py` — реестр инвест-идей
- `views/finmodel.py` — финмодели (аренда / продажа / покупка+аренда), мультивалютные
- `views/market.py` — «Анализ рынка»: вторичка (kufar.by/realt.by) по отслеживаемым адресам + цены застройщика (bir.by) по 16/11 кварталу; фильтры, архив ушедших объявлений, курс валют в сайдбаре
- `views/data_entry.py` — «Ввод данных»: единая страница для внесения прогресса капитала, сделок, объектов недвижимости и помесячных срезов баланса

### Данные

- `db.py` — локальная база (SQLite, `~/.trashman_family_office/family_office.db` или `$APP_DATA_DIR`): капитал, сделки, недвижимость, помесячные срезы баланса. `load_*()`-функции отдают те же структуры (DataFrame/dict), что раньше парсились из Google Таблицы, — views их не отличают
- `migrate_from_sheet.py` — разовый перенос истории из старой Google Таблицы в `db.py`
- `parsers.py` — разбор листов книги (используется только миграцией)
- `auth.py` — пароль на вход (переменная окружения `APP_PASSWORD`)

### Рынок недвижимости и цены (`views/market.py`)

- `market_kufar.py`, `market_realt.py` — вторичка по адресам из `config.py` (обычные HTTP-запросы, без браузера)
- `market_bir.py` — прайс-лист застройщика; использует headless-браузер (Playwright), потому что список юнитов на bir.by подгружается по кнопке «Показать ещё» без предсказуемого API
- `bnb_rates.py` — курс RUB/USD и EUR/USD с bnb.by (кросс-курс через BYN)
- `*_store.py` (`market_store`, `bir_store`, `rates_store`, `docs_store`, `events_store`, `finmodel_store`, `ideas_store`, `entities_store`) — локальный кэш в `~/.trashman_family_office/` (переживает обновление кода/ZIP)
- `local_store.py`, `web_common.py` — общие мелочи (путь к локальному хранилищу, User-Agent для запросов)

### Разведка (`scouts/`, одноразовые скрипты — не часть приложения)

`*_scout.py` и `realt_probe.py` — использовались один раз, чтобы вскрыть формат
данных нужного сайта перед тем, как писать соответствующий парсер. Держим в
репозитории на случай, если сайт снова изменит вёрстку и разведку понадобится
повторить.
