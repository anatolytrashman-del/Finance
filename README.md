# Trashman Family Office

Локальный веб-дашборд на Streamlit поверх Google Таблицы — учёт капитала,
сделок, недвижимости, финмоделей и мониторинг рынка (kufar/realt/bir.by).

## Настройка

1. В Google Таблице: **Файл → Настройки доступа** → «Все, у кого есть ссылка» → **Читатель**.
2. Проверь/поменяй ID таблицы в `config.py` (`GOOGLE_SHEET_ID`), если ссылка отличается.
3. Установи зависимости:
   ```bash
   pip install -r requirements.txt
   python3 -m playwright install chromium   # один раз — нужен для «Анализ рынка» (bir.by)
   ```

## Запуск

```bash
streamlit run app.py
```

Откроется `http://localhost:8501`. После того как раз в месяц дополнишь таблицу — нажми
«🔄 Обновить данные» в боковой панели, приложение перечитает файл.

## Структура

- `app.py` — роутер навигации (запускается через `streamlit run app.py`), общий шрифт и логотип
- `views/dashboard.py` — дашборд капитала (KPI-карточки, капитал в $/₽, прирост по годам, долг/капитал, структура активов, доходы; последняя точка капитала/долга пересчитывается по текущему курсу bnb.by, см. `balance_live.py`)
- `views/balance.py` — баланс на последний срез: активы/обязательства по категориям, итого по портфелю
- `views/deals.py` — реестр сделок (инвестиции/продажи/дивиденды) с фильтрами по периоду
- `views/real_estate.py` — портфолио объектов недвижимости с картой и итогами
- `views/documents.py` — архив документов по объектам (ссылки на Google Диск)
- `views/ideas.py` — реестр инвест-идей
- `views/finmodel.py` — финмодели (аренда / продажа / покупка+аренда), мультивалютные
- `views/market.py` — «Анализ рынка»: вторичка (kufar.by/realt.by) по отслеживаемым адресам + цены застройщика (bir.by) по 16/11 кварталу; фильтры, архив ушедших объявлений, курс валют в сайдбаре

### Данные

- `data_source.py` — загрузка книги из Google Таблицы (кэшируется, пересчитывается только по кнопке «Обновить данные»)
- `parsers.py` — разбор листов «Прогресс», «Сделки», «Real Estate» и месячных срезов баланса

### Рынок недвижимости и цены (`views/market.py`)

- `market_kufar.py`, `market_realt.py` — вторичка по адресам из `config.py` (обычные HTTP-запросы, без браузера)
- `market_bir.py` — прайс-лист застройщика; использует headless-браузер (Playwright), потому что список юнитов на bir.by подгружается по кнопке «Показать ещё» без предсказуемого API
- `bnb_rates.py` — курс RUB/USD и EUR/USD с bnb.by (кросс-курс через BYN)
- `*_store.py` (`market_store`, `bir_store`, `rates_store`, `docs_store`, `events_store`, `finmodel_store`, `ideas_store`) — локальный кэш в `~/.trashman_family_office/` (переживает обновление кода/ZIP)
- `local_store.py`, `web_common.py` — общие мелочи (путь к локальному хранилищу, User-Agent для запросов)

### Разведка (`scouts/`, одноразовые скрипты — не часть приложения)

`*_scout.py` и `realt_probe.py` — использовались один раз, чтобы вскрыть формат
данных нужного сайта перед тем, как писать соответствующий парсер. Держим в
репозитории на случай, если сайт снова изменит вёрстку и разведку понадобится
повторить.
