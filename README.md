# Капитал — дашборд

Локальный веб-дашборд на Streamlit поверх Google Таблицы с учётом капитала.

## Настройка

1. В Google Таблице: **Файл → Настройки доступа** → «Все, у кого есть ссылка» → **Читатель**.
2. Проверь/поменяй ID таблицы в `config.py` (`GOOGLE_SHEET_ID`), если ссылка отличается.
3. Установи зависимости:
   ```bash
   pip install -r requirements.txt
   ```

## Запуск

```bash
streamlit run app.py
```

Откроется `http://localhost:8501`. После того как раз в месяц дополнишь таблицу — нажми
«🔄 Обновить данные» в боковой панели, приложение перечитает файл.

## Структура

- `app.py` — роутер навигации (запускается через `streamlit run app.py`)
- `views/dashboard.py` — дашборд капитала (KPI-карточки, капитал в $/₽, прирост по годам, долг/капитал, структура активов, доходы)
- `views/deals.py` — реестр сделок с фильтрами и графиком инвестиций по годам
- `views/real_estate.py` — портфолио объектов недвижимости с итогами
- `data_source.py` — загрузка книги из Google Таблицы
- `parsers.py` — разбор листов «Прогресс», «Сделки», «Real Estate» и структуры активов
